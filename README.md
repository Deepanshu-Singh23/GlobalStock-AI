# 🌍 GlobalStock AI
### Global Stock Market Research & Analytics Platform

GlobalStock AI is a Python-based stock market research and analytics platform designed to explore global securities, analyze historical market data, evaluate company fundamentals, and generate data-driven financial insights.

## 🚀 Key Features

### 1. Global Market Intelligence
- Global stock market overview
- Country-wise and exchange-wise analytics
- Market movers and performance analysis
- Interactive market heatmaps
- Global stock discovery

### 2. Advanced Stock Screener
- Technical screening
- Historical return analysis
- Stock filtering by country and exchange
- Technical indicators

### 3. Company Fundamentals
- Company information and classification
- Market capitalization
- P/E ratio and EPS
- Revenue and profitability metrics
- Company fundamentals analysis

### 4. Financial Statements
- Annual financial statements
- Quarterly financial statements
- Revenue and net income analysis
- Operating income and gross profit

### 5. Portfolio Risk Analytics
- Historical portfolio analysis
- Risk and volatility metrics
- Portfolio performance evaluation

### 6. ETF Analysis
- ETF comparison
- ETF holdings research
- Fund information and performance metrics

### 7. AI Research Assistant
- Automated stock research reports
- Financial data summaries
- Research-oriented analytics

### 8. Data Quality Monitor
- Missing-value detection
- Duplicate record identification
- Country and exchange coverage
- Historical price-file auditing
- Dataset quality scoring

## 🛠️ Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- yfinance
- CSV-based data processing

## 📊 Data Sources

- Yahoo Finance through yfinance
- Historical market datasets
- Locally processed CSV datasets

**Disclaimer:** Market information may be delayed or unavailable. This platform is intended for educational and research purposes, not financial advice.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Deepanshu-Singh23/GlobalStock-AI.git
```

Navigate to the project:

```bash
cd GlobalStock-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Project Objective

The objective of GlobalStock AI is to create a centralized platform for global stock market exploration, historical financial analysis, company research, and portfolio risk assessment.
